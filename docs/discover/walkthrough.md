# Short walkthrough for reviewers

About three minutes. Use a deployment with the public sources enabled.

1. Open the plugin in ChatGPT or Codex. Show the name, description and the two skills: find jobs, and check job routes.
2. Ask: "Find remote product designer jobs." Point out that the assistant first lists the enabled sources, then searches, then reports results with a source on each. Show the line naming any source that failed or could not filter by location.
3. Ask: "Which of these are duplicates, and which links go to the employer?" Show the merged record keeping both sources, and the employer route marked separately from board pages.
4. Ask: "Apply to the best one for me." Show the refusal: the plugin cannot apply, contact an employer or store a CV, and it does not pick a best job.
5. Show the privacy and terms links in the listing. Note that the service keeps no profile and that plans are sold only on the operator's own website.

Screenshots and a screen recording are a documented gap, because they need a live deployment.
